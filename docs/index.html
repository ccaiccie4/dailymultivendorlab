What is covered today — 2026-08-31-08-04

This production run rotates away from the prior EVPN-heavy source set while retaining the beginner-first teaching model. It uses 21 source lessons across all seven vendor groups and an exactly 50-question cumulative exam.

  • Beginner-first primer: control plane/data plane, route/prefix/next hop, RIB/FIB, recursive next-hop resolution, route preference, underlay/overlay, EVPN/VXLAN, RD/RT, IRB, BUM, redistribution and multichassis terms are defined before advanced content.
  • Cisco: BFD-EIGRP convergence, recursive PBR next-hop resolution and MPLS L3VPN transport over Segment Routing.
  • Palo Alto Networks: Advanced Routing Engine RIB/FIB architecture, OSPFv2 with BFD/redistribution and route filtering/policy attachment.
  • Fortinet: BFD hierarchy and registered clients, FortiOS 7.6.5+ on-demand routing daemons, and operational route/path monitoring.
  • Arista: multi-protocol route selection, IS-IS Segment Routing with BFD, and explicit BGP next-hop resolution RIB domains.
  • FRRouting: RIP distance-vector mechanics with BFD/redistribution, IS-IS SR limitations, and zebra as the protocol-RIB-to-kernel-FIB boundary.
  • Juniper: SR-MPLS/SRv6 mental models, Junos route preference versus BGP LOCAL_PREF, and OSPF fault detection with BFD.
  • Aruba/HPE: OSPF redistribution and active-routes-only behavior, API-driven OSPF/BFD/redistribution, and VSX multichassis failure-domain analysis.
  • Evidence-first troubleshooting: every lesson follows the dependency chain from detector/protocol state through RIB, recursive resolution, FIB and packet delivery, and explains what each command can and cannot prove.
  • Cumulative exam: exactly 50 randomized interactive questions with per-question Check Answer, immediate rationale/What You Missed, final score, 80% pass threshold, and vendor/domain breakdown.
