What is covered today

Today's lab focuses on evidence-first troubleshooting across Cisco, Fortinet, Palo Alto Networks, Arista, Aruba/HPE, Juniper, and FRRouting. The workbook connects protocol theory to actual deployment behavior instead of treating each vendor as an isolated topic.

BGP / EVPN / VXLAN
VTEP next-hop recursion, EVPN multihoming, Type-2/3/5 routes, logical VTEPs, underlay versus overlay.
Route Redistribution
OSPF↔BGP policy, route tags, route-map attachment points, loop prevention, RIB selection, and migration caveats.
Fortinet SD-WAN
BGP multipath eligibility, installed next hops, SD-WAN steering, and forwarding-state verification.
Multichassis & Layer 2
EVPN all-active, VSX/MLAG/vPC concepts, LACP, VLAN/trunk behavior, BUM and L2-over-L3 design.
MPLS / IS-IS / Segment Routing
VRFs, label forwarding, IS-IS Level 2, FRR Segment Routing, capability and interoperability limits.
50-question cumulative exam
Current material plus prior OSPF, BGP, EIGRP, RIP, IS-IS, MPLS, EVPN/VXLAN, SD-Access, RIB/FIB and troubleshooting concepts.
