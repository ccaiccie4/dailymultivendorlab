What is covered today — 2026-09-02-08-01

Today's workbook uses 21 fresh beginner-first engineering lessons across all seven vendor groups and exactly 50 cumulative interactive questions.

  • Foundations primer: control plane/data plane, RIB/FIB, recursive next-hop resolution, route preference, VXLAN/VTEP/VNI, EVPN RD/RT, IRB, BUM, redistribution and multichassis concepts are defined before advanced material.
  • Cisco: BGP Diverse Path with route reflectors, multiple locally sourced paths across redistribution, and MPLS Traffic Engineering Fast Reroute link/node protection.
  • Palo Alto Networks: Advanced Routing Engine static-route path monitoring, BGP graceful restart stale-route behavior, and OSPF graceful restart with strict LSA checking.
  • Fortinet: OSPF restart-on-topology-change, fast physical-link failure notification, and ADVPN Dynamic BGP versus hub route reflection.
  • Arista: dynamic BGP listen ranges and peer groups, VARP active-active first-hop routing, and IS-IS graceful restart state/timers.
  • FRRouting: LDP label state from ldpd through zebra to the kernel, ECMP/backup nexthop groups, and planned/unplanned OSPF graceful restart.
  • Juniper: BGP/EIBGP multipath, LDP session protection over alternate IP paths, and Long-Lived Graceful Restart with stale-route tradeoffs.
  • Aruba/HPE: VSX Active Gateway versus VRRP, AOS-CX Policy-Based Routing, and New Central community-list/route-map APIs for BGP policy automation.
  • Evidence-first troubleshooting: every lesson separates protocol/session state, policy, RIB ownership, recursive next-hop reachability, FIB/tunnel/label programming and actual packet delivery.
  • Cumulative exam: exactly 50 randomized questions with individual Check Answer, rationales, What You Missed feedback, 80% PASS threshold, and domain/vendor performance breakdown.
