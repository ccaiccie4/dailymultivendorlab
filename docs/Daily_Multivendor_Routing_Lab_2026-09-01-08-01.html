Redistribution-loop library

Mark origin at the first boundary and deny that origin at a return boundary. Decide whether only active routes may be exported. Native OSPF/BGP/EIGRP loop prevention does not prevent cross-protocol feedback.

L2-over-L3/MPLS/EVPN/SD-Access

All overlays contain service state and transport state. VXLAN uses VTEP/VNI, MPLS uses FEC/labels, SD-Access uses LISP mapping plus VXLAN. Prove service → transport recursion → forwarding → MTU/counters.
