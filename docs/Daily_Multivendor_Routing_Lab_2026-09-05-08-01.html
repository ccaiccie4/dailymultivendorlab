Networking Foundations Primer

Control plane vs data plane

Control plane exchanges topology/routes/labels; data plane is the FIB, adjacency, tunnel or label operation that actually forwards.

Route/prefix/next hop

A prefix names a destination range, a route is one candidate path, and a next hop is the immediate or recursively resolved forwarding target.

RIB/FIB/adjacency

The RIB selects a route; the FIB is forwarding-ready state; the adjacency is the final neighbor/tunnel/label relationship needed to transmit.

Recursive resolution

A BGP/overlay next hop may recurse through multiple routes until a connected adjacency or tunnel is found.

Route preference

Different protocols can offer the same prefix; administrative distance/route preference decides cross-protocol ownership.

Underlay/overlay

The underlay carries infrastructure reachability; overlays such as VXLAN/EVPN/MPLS services/OTP depend on it.

VXLAN/VTEP/VNI

VXLAN adds UDP/IP encapsulation; VTEPs add/remove it; VNI identifies a logical L2/L3 service.

EVPN/RD/RT

EVPN carries endpoint/service reachability; RD makes VPN routes unique; RT controls import/export membership.

IRB/anycast gateway

IRB connects bridging and routing; anycast gateway presents the same first-hop identity on multiple nodes.

BUM

Broadcast, unknown-unicast and multicast need replication or multicast handling because one remote unicast destination is not known.

Redistribution/policy

Redistribution re-originates routes between protocols; tags/communities/prefix lists/route maps preserve intent and prevent feedback.

LACP/multichassis

LACP bundles links; MLAG/vPC/VSX/MC-LAG coordinate chassis; EVPN multihoming uses ESI and DF election.

VRF/VLAN/trunk

A VRF is an isolated L3 table, VLAN is an L2 broadcast domain, trunk carries multiple VLANs.

1. Cisco Systems — EIGRP Over the Top (OTP)

Platform: Cisco IOS XE / ASR1000
Classification: authoritative vendor documentation / technical engineering material

Exact source: https://www.cisco.com/c/en/us/td/docs/routers/ios-xe/ip-routing/b-ip-routing/m_ire-eigrp-over-the-top.html

Beginner foundation — terms you need before this lesson

EIGRP remains the enterprise control plane while LISP encapsulation carries traffic across a WAN that only needs locator reachability.

Why this exists / architecture

EIGRP route learned → OTP control state selects remote locator → LISP encapsulation → provider IP transport → remote decapsulation → local forwarding.

Command and evidence teaching

Verify EIGRP topology/OTP state separately from locator reachability; WAN ping does not prove enterprise route learning.

Failure boundary / lab

Break remote-locator reachability while preserving local EIGRP neighbor state.
